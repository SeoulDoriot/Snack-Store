# Claude Working Instructions
## Project
This is Hak Shop, a snack shopping app/website.
The project already has an existing design direction. Do not redesign from scratch.
## Main Rule
Preserve the current Figma / Claude Design style.
Do NOT:
- Delete existing screens
- Replace the UI with a generic template
- Rewrite the whole project
- Remove current product cards
- Remove current navigation
- Change the design direction without permission
Claude should only:
- Fix broken code
- Add missing features
- Improve the current UI carefully
- Keep the same visual style
- Make small safe changes
## Design Style
The UI should feel like:
- Apple style
- Notion style
- Clean
- Minimal
- Premium
- Smooth
- Easy to use

Avoid:

- Crowded UI

- Random colors

- Heavy gradients

- Generic ecommerce design

- Too much top spacing

## Navigation

The app has 4 main navigation areas:

1. Home

2. Categories

3. Cart

4. Settings

## Home Page

Home should include:

- Header

- Search

- Category chips

- Featured promo poster carousel

- Recommended products

- Popular products

- New arrivals

The promo poster carousel is not a product card.

It should:

- Be large and visual

- Show snack posters

- Have no price

- Have no Add to Cart button

- Be clickable to filter/scroll to the related category

## Product Cards

Product cards should include:

- Product image

- Product name

- Short description

- Price

- Wishlist heart button

- Add to Cart button

The style should be close to the Figma design:

- Rounded image

- Rounded card

- Bold product name

- Black pill Add to Cart button

- Clean spacing

## Cart

Cart should support:

- Add product

- Remove product

- Increase quantity

- Decrease quantity

- Show subtotal

- Show total

- Checkout button

- Empty cart state

## Wishlist

Wishlist should support:

- Tap heart to save item

- Tap again to remove

- Filled heart for saved item

- Wishlist visible in Settings or account area

## Settings

Settings should include:

- Profile card

- Edit profile

- Wishlist

- Delivery address

- Payment methods

- Notifications

- Help center

- Logout

## Development Rules

Before editing code:

1. Read the existing files first.

2. Understand the current structure.

3. Tell me what files will be changed.

4. Make small safe edits.

5. Do not rewrite the whole app.

6. Keep existing UI unless I ask for redesign.

7. Fix compile/build errors after changes.

## Final Goal

Make the project run smoothly while keeping the original design style.
